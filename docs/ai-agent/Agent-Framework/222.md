
今天我们介绍Microsoft Agent Framework 中Harness Agent 提供的两种上下文提供器：TodoProvider 和 AgentModeProvider分别负责待办事项管理和工作模式管理。
它们让 Agent 能够先制定计划，再进入执行模式，并在处理多步骤任务时持续跟踪进度。

两种上下文提供器支持长时间运行的任务：

- **待办事项提供器（Todo Provider）**：保存可跟踪的工作项，并向智能体提供添加、完成、删除和查看工作项的工具。
- **智能体模式提供器（Agent Mode Provider）**：保存当前运行模式，并向智能体提供读取或切换模式的工具。

如果只需要规划功能，可以直接组合这两种提供器；也可以使用 Harness Agent，将它们作为默认流水线的一部分启用。

## TodoProvider(待办事项工具)

.NET 和 Python 提供器向模型开放相同的工具：

| 工具 | 用途 |
|---|---|
| `todos_add` | 添加一个或多个事项，包含标题和可选的描述。 |
| `todos_complete` | 将一个或多个事项标记为已完成，并附上完成原因。 |
| `todos_remove` | 删除不再需要的事项。 |
| `todos_get_remaining` | 返回尚未完成的事项。 |
| `todos_get_all` | 返回所有事项，包括已完成和未完成的事项。 |

提供器会在每次运行前注入当前待办事项列表，让智能体能够继续处理尚未完成的工作。

## AgentModeProvider(规划模式与执行模式)

`AgentModeProvider` 默认提供 `plan` 和 `execute` 两种模式：

1. **规划（Plan）**：采用交互方式。智能体分析需求、创建待办事项、提出澄清问题、展示计划，并在切换模式前征求用户同意。
2. **执行（Execute）**：采用自主方式。智能体按照计划开展工作，在细节不明确时作出合理选择，并将完成的待办事项标记为已完成。

提供器开放了 `mode_get` 和 `mode_set` 工具。其指令要求模型仅在用户明确允许切换时使用 `mode_set`。应用也可以直接切换模式，此时提供器会在下一次运行时注入一条模式变更通知。

如果你想自定义模式的话，可以通过 `AgentModeProviderOptions.Modes` 配置新的模式名称和指令。

## 如何使用 TodoProvider

如果让Agent能够使用待办事项工具，我们需要实例化一个TodoProvider，并将实例赋值给ChatClientAgentOptions.AIContextProviders上下文中，这样Agent就可以使用代办事项工具。

```csharp
using var todoProvider = new TodoProvider();
AIAgent agent = new AIProjectClient(new Uri(endpoint), new DefaultAzureCredential())
    .AsAIAgent(new ChatClientAgentOptions
    {
        Name = "PlanningAssistant",
        ChatOptions = new ChatOptions
        {
            ModelId = model,
            Instructions = "你是一个有帮助的计划助理。使用你的待办事项列表来计划和跟踪多步骤的工作。",
        },
        AIContextProviders = [todoProvider],
    });
```


我们可以使用`todoProvider.GetAllTodosAsync`方法返回Agent的生成的所有代办项目列表，每个代办项目列表用 `TodoItem`类表示。该类提供了四个属性：`Id`、`Title`、`Description` 和 `IsCompleted`。


```csharp
string[] userMessages =
[
    "我是组织一个小型团队外出活动。你能帮我计划吗？把工作分解成一个待办事项列表。",
    "我已经预订了场地并发送了邀请。请更新列表。",
    "实际上，我们跳过餐饮，改为计划一次集体徒步旅行。相应地更新计划。",
];
foreach (string userMessage in userMessages)
{
    Console.WriteLine($"用户: {userMessage}");
    Console.WriteLine($"代理: {await agent.RunAsync(userMessage, session)}");

    await PrintTodoListAsync(todoProvider, session);
    Console.WriteLine();
}
static async Task PrintTodoListAsync(TodoProvider todoProvider, AgentSession session)
{
    IReadOnlyList<TodoItem> todos = await todoProvider.GetAllTodosAsync(session);

    Console.WriteLine("--- 当前待办事项列表 ---");
    if (todos.Count == 0)
    {
        Console.WriteLine("  (空)");
        return;
    }

    foreach (TodoItem todo in todos)
    {
        string status = todo.IsComplete ? "x" : " ";
        Console.WriteLine($"  [{status}] {todo.Id}. {todo.Title}");
    }
}
```

## 如何使用 AgentModeProvider

如果让Agent能够使用模式工具，我们需要实例化一个AgentModeProvider，并将实例赋值给ChatClientAgentOptions.AIContextProviders上下文中，这样Agent就可以使用模式工具。

```csharp
AgentModeProvider modeProvider;
string[] availableModes;
modeProvider = new AgentModeProvider();
availableModes = ["plan", "execute"];

AIAgent agent = new AIProjectClient(new Uri(endpoint), new DefaultAzureCredential())
    .AsAIAgent(new ChatClientAgentOptions
    {
        Name = "ModeAwareAssistant",
        ChatOptions = new ChatOptions
        {
            ModelId = model,
            Instructions = "你是一个乐于助人的助手。遵循当前操作模式所要求的流程和行为。",
        },
        AIContextProviders = [modeProvider],
    });
```

可以通过 `AgentModeProviderOptions.Modes` 自定义模式名称和指令。

## 在 Harness Agent 中使用规划与待办事项

如果还需要 Harness Agent 预先配置的历史记录、记忆、审批和可观测性流水线，可以采用这种配置方式。

`HarnessAgent` 默认启用 `TodoProvider` 和 `AgentModeProvider`。通过 `HarnessAgentOptions`，可以配置模式提供器，以及可选的、由待办事项驱动的循环：

```csharp
using Microsoft.Agents.AI;
using Microsoft.Extensions.AI;

var options = new HarnessAgentOptions
{
    AgentModeProviderOptions = new AgentModeProviderOptions
    {
        DefaultMode = "plan",
    },
    LoopEvaluators =
    [
        new TodoCompletionLoopEvaluator(
            new TodoCompletionLoopEvaluatorOptions
            {
                Modes = ["execute"],
            }),
    ],
    LoopAgentOptions = new LoopAgentOptions { MaxIterations = 10 },
};

HarnessAgent agent = chatClient.AsHarnessAgent(options);
// 等效的构造方式：new HarnessAgent(chatClient, options)
AgentSession session = await agent.CreateSessionAsync();
```

设置 `DisableTodoProvider` 或 `DisableAgentModeProvider`，可以禁用对应的默认提供器。如果要使用自行配置的 `TodoProvider`，先禁用默认提供器，再通过 `AIContextProviders` 添加自己的实例。可以通过 `agent.GetService<TProvider>()` 获取已启用的提供器。


## 总结

这节我们介绍了 Harness Agent 提供的两种上下文提供器：TodoProvider 和 AgentModeProvider。通过 TodoProvider，Agent 可以管理待办事项列表，跟踪任务的完成情况；通过 AgentModeProvider，Agent 可以在不同的工作模式之间切换，实现规划与执行的分离。结合 LoopAgent 和 TodoCompletionLoopEvaluator，可以实现基于模式的循环执行，直到所有待办事项完成。
